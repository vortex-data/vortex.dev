# Security Policy

This repository holds the vortex.dev website and bench.vortex.dev. It follows the Vortex project's security policy: <https://github.com/vortex-data/vortex/blob/develop/SECURITY.md>.

## Reporting a vulnerability

Email <security@vortex.dev>. Do not report security vulnerabilities through public GitHub issues, discussions or pull requests.

Include, where you can:

- the affected site or page (vortex.dev or bench.vortex.dev), or the file in this repository;
- a description of the issue and its impact;
- steps to reproduce or a proof of concept;
- whether the issue is publicly known or being actively exploited.

The project's policy gives the response targets and the emergency process for severe or actively exploited issues.
